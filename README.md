# Fabric.js Canvas Editor

## Overview
This project demonstrates a simple interactive canvas using Fabric.js.

## Features
- Add shapes and text
- Drag and resize elements
- Background image support
- Zoom functionality

## Tech Stack
- JavaScript
- Fabric.js
- HTML/CSS
